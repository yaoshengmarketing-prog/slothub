# Slot Hub｜單款頁遊戲圖片與影片｜第一版規則定案

> 僅供審閱定案紀錄；不授權合併正式站、不接遊戲模板、不部署。

本文件為已收斂共識的第一版規則定案。規則定案不代表個別素材使用依據已全部補齊，也不構成正式模板接線或發布授權。

## 1. 收錄邊界

- **完整盤面圖與影片皆非遊戲收錄或資料頁上架門檻。** 沒有影音素材，仍可收錄遊戲及提供既有資料。
- 完整盤面圖是補圖與展示目標；缺少時記錄於後台，不阻擋其他資料工作。
- 影片是否合格，只影響是否展示及如何展示影片。
- 功能符號、banner 或合格影片，均不能代替完整盤面圖，也不能使盤面缺口被標為完成。

## 2. 完整盤面認定

**定義：完整盤面圖是經核對屬於同款遊戲，能辨認當下盤面的完整邊界、主要符號，以及該狀態原本可見的主要操作入口，並如實標示已知模式及版本限制的圖片。**

### 接受條件

- 桌機橫式、手機直式皆可，保留素材原比例。
- 實際截圖或原廠裝置合成圖皆可，但其中的遊戲區須符合完整盤面定義。
- 至少能辨認盤面邊界、主要符號，以及該狀態原本可見的旋轉、投注等主要操作入口位置。
- 若已確認該狀態原本不顯示操作入口，可保留並註明；不得補畫操作區，也不稱為完整操作介面教學。無法判明是原本隱藏、裁切或遮擋時，不逕認定完整盤面。
- 不要求所有小字可讀，也不要求展開所有操作選單。
- 動態擴張盤面可呈現截圖當下的完整狀態，不要求一張圖片涵蓋所有尺寸。

### 拒絕作為主要完整盤面的條件

- 只有功能符號、角色、Logo、封面或宣傳 banner。
- 裁切、模糊、遮擋或宣傳文字，使必要區域無法辨認。
- 合成圖中的遊戲區過小，放大後仍無法辨認。
- 只有結算、選單或過場畫面，沒有實際盤面。
- 無法確認同款身份，或經重繪、拼接而無法確認原始遊戲畫面。
- 已知是外觀明顯不同的舊版本，卻用來代表目前版本。

拒絕的是其「主要完整盤面」用途。功能圖或宣傳圖可作輔助素材，但不得視為完整盤面，也不得計入盤面展示完成；舊圖可保存為歷史版本。某模式的完整盤面與一般遊戲盤面是否補齊分開判定；完整的 Bonus 盤面只能代表該模式，不代表一般遊戲盤面已補齊。

### 版本與模式標示

- 保存發布者、原始圖片網址、所屬遊戲頁及本站核對日期。
- 來源有版本名稱或識別碼才填寫；沒有則保留「來源未註明版本」。
- 已知是一般遊戲、免費旋轉或特定功能時，標示實際模式，不互相代稱。
- 圖片拍攝／發布日期與本站核對日期分開保存；未知日期不補猜。
- 不從外觀推定 RTP、市場或遊戲設定。
- 前台精簡呈現影響理解的模式及限制，完整查核紀錄留於後台；不要求每個版本與模式都補滿圖片。

### 素材來源與使用依據

- 圖片與影片的素材來源與公開使用依據分開保存。記錄適用的公開使用條款、授權／同意，或經評估的其他使用依據；未知不得標為已授權，也不以原廠公開發布或標示來源代替使用依據。
- 有既有素材使用規範時直接引用，不重建流程；同一份條款適用多份素材時可共用紀錄。

## 3. 展示方式

- 區塊順序維持：**快速看懂 → 遊戲畫面 → 官方 Demo**；暫不整頁移動數據區。
- 圖片附來源與一句「這裡可以看懂什麼」，支援既有圖片放大及鍵盤操作。
- 採 B：經核對同款身份、來源及具體用途的輔助圖片可以獨立展示，不以完整盤面圖或合格影片存在為前提；辨認特殊符號也屬具體用途，不要求每張圖片承擔完整教學。
- 依圖片實際提供的資訊判斷，不因名稱是 banner 就一律拒絕；僅重複封面或宣傳口號而沒有額外用途者不展示，也不為填補缺圖而採用。
- 前台依素材擇一顯示「功能符號圖」或「宣傳圖」等適用種類，並就近標示一次「非完整盤面」；保留用途及來源，不整串照抄種類名稱或重複解釋同一限制。
- 圖片中的額外宣傳主張沿用既有資料採用規則，不因種類標示清楚就視為已核實。
- 沒有合適影音素材時，前台不產生空影音區，缺口只記後台。
- 只有圖片時，不產生播放器或不必要的播放器請求。
- 官方 Demo 維持獨立站外入口，不塞入影音區，也不替代盤面展示。

## 4. 影片選片

### 用途

影片須經實際觀看，能補充靜態圖片難以呈現的動作或流程，例如：

- 連消、補位、符號擴展等盤面變化。
- 進入 Bonus 後的畫面、操作或功能流程。
- 特定功能如何運作及呈現。

觀看範圍至少須足以支持本站的用途說明。描述畫面狀態，可依已看見的畫面；描述動作或流程，須實際看過相應的連續過程，不從抽樣畫面補出未核對的規則。播放至結束不等於完成內容判讀，也不要求逐影格審片。

以下不足以單獨支持採用：

- 只有品牌、角色動畫或宣傳口號。
- 靜態圖片輪播，沒有增加玩法理解。
- 只秀大獎結果，看不懂過程，或以輸贏暗示機率。

每支影片均須附來源、發布者及觀看用途。影片不作 RTP、觸發率、常見結果或其他機率證據。

內容核對、來源站可播放與本站可嵌入，分別保存核對結果、範圍及日期，不以其中一項通過代表全部通過。

### 數量與來源

- 每款原則上一支，最多兩支；第二支須回答不同問題。
- 用途相當時優先原廠；第三方能提供更清楚的玩法紀錄時，可以採用。
- 原廠影片須經身份、內容及實際嵌入核對，才提供點擊載入。影片仍採用且來源入口有效期間，持續提供站外觀看連結，不因播放器正常而隱藏；確認來源失效後依第 5 節移除。
- 第三方影片維持僅站外觀看。
- 原廠與第三方的展示方式差異是第一版控制採用範圍與維護成本的營運政策，不代表原廠內容自動正確或第三方內容沒有價值。
- 不自動播放，不下載重傳他人影片。
- 未觀看的影片只留候選紀錄，不作正式觀看入口。
- 時間點只在已觀看且確有用途時提供；短片不強制增加片段跳轉。

## 5. 失效處理

| 情況 | 前台處理 | 後台紀錄 |
|---|---|---|
| 嵌入失敗，來源站仍能播放 | 移除失效播放器，改為站外觀看 | 測試網址、錯誤、核對日期及處理結果 |
| 確認刪除、轉私人或內容換成別款 | 移除影片入口；圖片與遊戲資料保留 | 原來源、最後成功核對日及停用原因 |
| 單次連線或環境限制 | 不直接判定永久失效；原已核對影片可保留站外來源連結，但本次未確認可播時不宣稱是已驗證有效的退路 | 實際錯誤與未知狀態，記為待複查，不推測原因 |
| 從未看過內容且仍受限 | 不建立正式觀看入口 | 保留候選及待核對事項 |

- 「暫不可播」可作當次載入失敗提示，不長期保留無法操作的空播放器。
- 不繞過限制，不反覆重試同一路徑。
- 新增、替換、收到失效回報，或本次回查明確包含影音時檢查；首版不要求每日掃描全部影片。
- 其他資料欄位更新不自動觸發影音重驗，也不連帶刷新影音核對日期；只有實際核對的項目才能更新其對應日期。
