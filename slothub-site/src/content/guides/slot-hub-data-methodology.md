Slot Hub 不把每個找到的數字直接放進同一張排名表。遊戲名稱看起來相近，不代表規則相同；兩個數字都寫著 `96%` 或 `10,000×`，也不一定來自相同版本、基準與條件。

這篇文章說明本站如何整理資料，以及你在 Game detail、Compare 或 Provider 頁看到原廠文字、統一顯示、缺值、來源與核對日期時，應該怎麼讀。

## 1. 先分清原廠資料與 Slot Hub 統一顯示

**原廠資料**是遊戲廠商在 Game Rules、Paytable、Help、正式技術文件或官方遊戲頁中使用的名稱、數值、單位與條件。Slot Hub 會盡量保留這一層的原始語境，例如 `Winning ratio`、`LOW-MED` 或不同 RTP 版本。

**Slot Hub 統一顯示**是為了讓搜尋、探索與比較更容易閱讀而建立的編輯層。例如，不同廠商可能用文字、數字或品牌名稱描述波動度；只有語意足以承接時，本站才會另外提供統一分類。

統一顯示不是原廠改口，也不是全產業共同標準。當原始定義不足時，本站寧可保留原文或缺值，也不強行換算。

| 頁面顯示 | 代表什麼 | 閱讀重點 |
| --- | --- | --- |
| 原廠標籤或原文 | 來源實際使用的名稱、數字或單位 | 回到來源確認版本、基準與條件 |
| Slot Hub 統一值 | 依已核對語意建立的共同顯示層 | 可協助篩選，但不取代原文 |
| 缺值 | 目前未知、未公開、未取得或無法安全統一 | 不推論為 0、沒有或不支援 |

## 2. 來源有優先順序，但仍要看完整語境

精確規則與數值優先採用官方 Game Rules、Paytable、遊戲內 Help、正式技術文件與官方遊戲頁。官方發布稿可補充發行與功能資訊；官方授權合作方只有在官方資料缺少時作補充，並應清楚標示來源角色。產業媒體或資料庫主要用來找線索與交叉核對，不取代精確規則的第一方證據。

「官方」也不代表每段解讀都能直接成立。來源如果只寫單一符號上限，就不能改成整局 Max Win；來源如果列出多個 RTP，也不能自行決定哪個是所有市場的主要版本。閱讀[最高倍數 Guide](/guide/slot-max-win-explained/)與 [RTP Guide](/guide/rtp-explained/)時，可以看到這些基準差異如何影響判讀。

## 3. 缺值不是否定答案

頁面沒有顯示某個欄位，通常只代表 Slot Hub 目前沒有足以安全公開或統一的資料。它不等於：

- 數值是 0；
- 遊戲沒有該功能；
- 所有版本都不支援；
- 可以從同系列、Provider、畫面或其他欄位補猜。

只有原廠明確說明不支援，本站才能把它顯示成已確認的不支援。例如 Compare 中的 Bonus Buy 會區分「已確認不支援」與「尚未核實」，而不是把空欄一律當成「沒有」。

## 4. 多版本、不同市場與歷史文件不能自動合併

同一款遊戲可能有不同 RTP 設定、投注範圍、規則版本或市場配置。歷史文件中的數字，也不一定是目前仍可選的版本。

因此，Slot Hub 會盡量把主要顯示值、已核實版本與來源分開保存。若兩個來源互相衝突，應保留差異並縮小結論，而不是挑一個看起來最合理的數字。對遊戲規則有疑問時，先確認你查看的遊戲名稱、Provider、版本與來源是否一致。

## 5. 核對日期不等於原廠發布日期

Game detail 的「最後核對日期」代表 Slot Hub 最後一次檢查整筆資料的時間；每一筆來源旁的「核對日期」代表本站查閱該來源的時間。這兩個日期都不表示原廠在當日重新發布或再次確認所有欄位。

圖片的取得日期也只記錄素材何時被保存，不代表遊戲發行日期。若規則、版本或官方頁面後來改變，仍需要新的核對才能更新本站資料。

## 6. 並排顯示不等於所有數字都能排名

資料大致可分成三種判讀層次：

1. **可直接比較**：身份與單位一致，且來源能支持同一基準，例如同格式的發行日期。
2. **必須保留警告**：可以並排，但要一起看原廠尺度、版本或條件，例如 RTP、波動度與 Max Win。
3. **不能統一比較**：基準不明、只描述局部功能，或不同來源語意無法對齊；此時只保留原文與來源。

Compare 的角色是把現有資料放在一起，幫你看出定義和缺值差異，不會計算哪款「比較容易贏」。RTP 不代表單次結果；波動度不預測下一次輸贏；最高倍數也不代表更常出現。需要細讀時，可分別前往[波動度 Guide](/guide/volatility-explained/)與[遊戲比較](/compare/)。

## 7. Provider 統計只代表目前收錄樣本

Provider Hub 顯示的機制、功能或資料覆蓋，只計算 Slot Hub 目前已發布的遊戲。樣本有 1 款時，頁面不會用它推論整家 Provider；樣本有多款時，比例也只描述本站收錄範圍，不代表該廠商全部產品線、全部市場或最新發行狀態。

因此，Provider 頁適合用來辨識本站目前有哪些資料與入口，不適合把樣本比例解讀成廠商整體品質或產品排名。

## 8. 實際查資料時的順序

你可以用以下順序快速核對：

1. 在[遊戲庫](/games/)或 Search 找到正確遊戲與 Provider。
2. 在 Game detail 先看原文名稱、核心數據與完整資料。
3. 遇到統一值時，同時查看原廠標籤；遇到缺值時保持未知。
4. 查看資料來源、版本與核對日期。
5. 需要並排時再加入 Compare；遇到陌生概念則前往專門 Guide。

這不是唯一操作順序，也不是品質評分。Slot Hub 的目標是讓每個可見結論都能說明它來自哪裡、能比較到什麼程度，以及哪些地方仍然不知道。
