Demo 通常是使用虛擬額度展示玩法的試玩模式；真錢模式則涉及實際資金。看起來是同一款遊戲，不足以證明兩邊 RTP、獎池、功能與配置完全相同，也不能拿幾次試玩結果預測真錢輸贏。

在 Slot Hub，**Provider 官方網站**與**遊戲 Demo 入口**是兩筆不同資料：廠商官網用於確認品牌身分；Demo 則必須指向可核對的同款遊戲試玩或展示頁。廠商首頁不能被標成 Demo，沒有可靠入口時就如實保留缺值。

## 官網與 Demo 為什麼要分開？

每款遊戲都應能連回它的 Provider 身分頁；每個 Provider 頁則應提供已核實的官方網站。這條鏈回答「誰製作這款遊戲」。

Demo 回答的是另一個問題：「是否有一個可公開進入、能對照此款遊戲的試玩或展示入口？」

| 入口 | 主要用途 | 不能拿來冒充什麼 |
| --- | --- | --- |
| Slot Hub Provider 頁 | 查看廠商介紹及本站收錄遊戲 | 外部官方網站 |
| Provider 官方網站 | 核對品牌身分、產品目錄與官方資訊 | 特定遊戲的 Demo |
| 官方遊戲頁 | 查看同款遊戲規則、規格或產品介紹 | 一定可操作的 Demo |
| Demo／試玩入口 | 使用虛擬額度或展示模式了解畫面 | 真錢結果、獲利證明 |

本站不在頁面內用 iframe 嵌入第三方 Demo。已核實的 Demo 會以清楚標示的外部連結開啟；如果廠商禁止嵌入、需要 Cookie、登入、年齡或地區確認，應由對方頁面自行處理。沒有 Demo 時，官網連結仍保留，但不會被改名成「試玩」。

## 畫面上怎麼分辨 Demo 與真錢？

- 尋找 Demo、Fun、Play for Free、試玩或功能展示等明確標示。
- 查看頁面是否連接真實錢包，以及目前使用的是虛擬額度還是實際資金。
- 虛擬餘額在試玩時也會增減，因此「數字有變」不能單獨證明是真錢模式。
- 有些 Demo 仍會要求登入、Cookie 同意、年齡或地區確認；這不會自動把它變成真錢模式。

若無法確認資金狀態，不要靠按下投注按鈕來測試。

## Demo 和真錢一定使用相同規則嗎？

不能全球一概而論。英國 Gambling Commission 的 RTS 6 要求其適用業者：在同一網站提供對應的免費與付費遊戲時，免費版本應使用相同規則，並準確呈現得獎機率與獎金分布。這項要求有管轄與適用範圍，不能替所有廠商、聚合平台或第三方 Demo 背書。

實際核對至少要看：

1. Provider 與遊戲原文名稱是否一致。
2. Game ID、文件版本或發布時期是否可辨認。
3. RTP 配置是否相同，是否另有多版本。
4. Paytable、Feature、Bonus Buy 與 Jackpot 資格是否一致。
5. 該頁是一般隨機試玩，還是刻意展示 Feature 的展示版。

同名、同封面或相似畫面，都不足以完成版本核對。

## Demo 分數會變成真錢嗎？

一般 Demo 的虛擬額度不能提款，也不等於帳戶中的真實資金。活動贈點、獎勵金或獨立競賽可能有另一套規則，不應和一般試玩餘額混在一起。

- 不把試玩得分當成可提領金額。
- 不把 Demo 的連勝當成切換模式後會延續的資格。
- 若頁面要求先付款才能領取所謂「試玩獎金」，先停止並查證。

## Demo 可以幫你做什麼？

Demo 最適合用來熟悉介面與核對規則：

- 找到 Balance、Bet、Win、Total Win、Paytable 與 Help。
- 辨認一般模式、Wild、Scatter 與 Feature 提示。
- 查看投注單位、按鈕位置及遊戲紀錄入口。
- 對照官方文件中的盤面與流程。

它不適合用來估計自己會不會贏。少量試玩不足以可靠估計觸發頻率或命中率；即使樣本增加，觀察值仍有不確定性，也不能直接套用到另一個版本。

## 功能展示版不是一般隨機試玩

廠商有時提供能直接開啟 Bonus、指定功能或特殊畫面的展示模式，也可能只提供宣傳影片。它們可以幫助理解流程，但不能用展示中出現 Feature 的頻率推論一般旋轉。

Slot Hub 會把可操作 Demo、官方遊戲頁、規則文件和影片視為不同來源角色。若來源只是遊戲介紹頁，就不把它標成「開始 Demo」。

## Slot Hub 如何呈現 Demo 資料？

遊戲頁會維持三層清楚關係：

1. **本站 Provider 頁**：每款遊戲都有對應廠商身分。
2. **Provider 官方網站**：每家廠商都應提供已核實的官網入口。
3. **Demo／試玩連結**：只有找到可核對的同款入口時才顯示；它是額外資料，不是官網的替代品。

如果只有官方遊戲介紹頁，會依實際內容標示，不會假稱可試玩。若只有聚合平台提供同款 Demo，也必須保存平台來源並清楚區分，不能冒充原廠官方入口。

外部 Demo 可能改址、停用或受地區限制；這類狀況代表入口目前不可用，不等於遊戲身分失效。本站不會下載、鏡像或改寫第三方試玩內容，也不使用 iframe 繞過對方限制。

## 常見誤解

- **「Demo 贏很多，真錢也會贏」**：短期結果不構成保證，也不會累積下一次的獲利資格。
- **「沒看到 Demo 字樣，就一定是真錢」**：標示也可能不足，仍須核對模式與錢包。
- **「同名遊戲的 Demo 一定是相同版本」**：RTP、Feature、獎池及市場配置都要另外確認。
- **「有廠商官網，就表示一定有 Demo」**：官方身分與是否公開試玩是兩件事。
- **「Demo 餘額可以提款」**：一般虛擬試玩額度不等於真實資金。

## 核對清單

- 是否明確標示 Demo、Fun、Play for Free 或功能展示？
- 遊戲名稱、Provider、版本或 Game ID 能否確認？
- 虛擬額度與真實錢包是否分清？
- RTP、Paytable、Feature 或獎池是否有版本差異？
- 連結實際指向同款遊戲，而不是廠商首頁或模糊目錄嗎？

資訊不足時就保留未知，不必用儲值或下注來查證。任何涉及實際資金的合法性、資格與限制，仍須按所在地規定另行確認。
