# Slot Hub 主要 Provider 候選地圖 v1

> 狀態：`INTERNAL WORKING MAP`
>
> 建立日期：2026-09-03
>
> 用途：支援第 10 項 Game／Provider 擴充第六至第十批的候選與備選安排。這不是完整產業名錄，不授權一次建立所有 Provider 公開頁，也不改變 Schema、taxonomy、產品功能或既有發布標準。

## 1. 使用原則

- Provider 是候選骨架，Game 仍按每批四款完成逐款驗證、收錄與發布。
- 優先補強目前只有 1～2 款的既有 Provider；新增 Provider 時，同批原則上至少發布兩款。
- 候選必須能確認遊戲身份、Provider、主要玩法、功能、官方或安全授權圖片，以及足以形成獨立 Game detail 的內容。
- RTP、波動度與 Max Win 優先核對官方遊戲頁、Rules、Paytable、Help、正式 PDF、Client Hub 與官方新聞稿。缺乏可靠精確值時維持「尚未核實」，不推論為原廠未公開。
- 官方授權合作方只補官方缺值，並在 Game sources 中清楚標示。搜尋摘要、一般資料庫、娛樂城與聯盟文章只作線索。
- 多版本與來源差異完整保存，不平均、不挑選較有利數字；不把 observed win、貨幣上限或局部功能倍率改寫為整局投注倍數。
- 單款資料或圖片不足時改用同批備選，不阻擋其他候選；只有現有 Schema／taxonomy 無法誠實承接時才停止。

## 5. 第六至第十批工作池

工作池是驗證順序，不是未核對資料的發布承諾；每批仍以四款通過正式驗證的遊戲為準。

| 第七批 | White Rabbit、Lil Devil、Vegas Gold、Drunken Sailors | Danger High Voltage、Coin Quest、Three Samurai | Big Time Gaming 2→4、Slotmill 3→5 |

| 第九批 | Moon Princess、Rise of Olympus、Divine Fortune、Twin Spin | Viking Runecraft、Fire Joker、Jack Hammer 2 | Play’n GO 與 NetEnt 深度、Ways／Paylines／Jackpot 補位 |
| 第十批 | Jump High 2、All Wilds、Golden Empire、Money Coming | Zeus M、Jungle Party、Fortune Gems、Agent Ace | CQ9 1→3、JILI 1→3，補亞洲搜尋入口 |

如果某款無法取得可靠身份、玩法、Feature 或安全官方圖片，優先使用同一 Provider 備選；不能因湊批而降低來源門檻。

## 6. 現有 taxonomy 承接結果

- 上述工作池目前可用既有 `paylines`、`ways-to-win`、`megaways`、`cluster-pays`、`pay-anywhere` 或保守的 `other` 表達主要 Mechanism。
- 候選功能只在官方資料直接支持且已存在 enum 時映射；GigaBlox 可在語意成立時使用既有 `giant-symbols`，品牌 Feature 名則保留於 `bonusFeatures`。
- 動態盤面、動態 ways、品牌化 respin 或 feature purchase 可以用現有原文欄位保存；不為工作池新增 enum。
- 任何候選若必須新增 Schema／taxonomy 才能不失真，立即移回候選池並使用備選；不以 `other` 掩蓋明確但尚未核准的新分類。
