## 結論

第八批採 Hacksaw Gaming 兩款與 Play’n GO 兩款，補強既有 Provider 與 Paylines／Cluster Pays 玩法。原定 Yggdrasil 候選 Tiki Tumble、Fat Santa 的現行官方遊戲頁無法取得，因此依連續批次規則暫放，改用具可達第一方頁面與官方圖片的備選。本批不新增 Provider、Schema 或 taxonomy。

## 邊界

- Hacksaw 官方列出的多個 RTP 數值保存為版本清單，不平均、不只取最高值。
- Play’n GO 公開頁沒有提供可直接保存的整款 RTP、波動度或整局 Max Win，本批維持缺值，不把 Feature 獎項改寫成整局上限。
- 不因 Bonus round 名稱而自動標記 Free Spins；只在官方明示 Free Spins 時加入該 Feature。
- Tiki Tumble、Fat Santa 保留為暫放候選，不用第三方資料補成正式紀錄。
