# 官方遊戲來源的地區限制與 IP 切換

> 適用：Game／Provider 收錄、官方產品目錄、單款資料、圖片與 Demo 核對。2026-10-30 由專案負責人補充實際可用的地區切換順序。

## 開工與判讀

1. 先讀 repo `AGENTS.md`、`docs/game-intake-workflow-v1.md`、`docs/game-demo-coverage-and-presentation-v1.md`，沿用既有去重、來源品質、圖片與發布閉環規則。
2. 先以目前網路開啟**確切官方 URL**。保存請求網址、時間、工具／瀏覽器、HTTP 狀態、實際內容類型、頁面標題、可見畫面與是否有重新導向。某些限制頁會回 HTTP 200，但內容是「403 Access Denied」HTML；須檢查內文與圖片位元組，不能只看狀態碼。
3. 官方網站、產品目錄或圖片打不開，表示**當前出口可能無法存取**，不表示該官方來源不可信、遊戲不存在或目錄已查完。先按下列順序重試；各地區結果分開記錄。不要從搜尋摘要或第三方頁面推斷官方目錄的完整數量。

## 地區切換順序

| 優先 | 方法 | 實際操作與證據 |
| --- | --- | --- |
| 1 | 美國 IP，自動 | 使用專案負責人已付費、可選擇美國出口的瀏覽器。先確認瀏覽器的美國地區選項已啟用，再重新開啟相同官方網址；記錄所用瀏覽器／地區選項、時間、HTTP 或畫面結果。2026-10-29 專案負責人曾測試可用；每次仍須確認本次實際出口，不能假定所有 Browser Use 執行環境都自動是美國。韓國網站也先試美國。 |
| 2 | 日本 IP，手動 | 若美國出口仍受限，請專案負責人在桌面手動切換為日本 IP，待其確認已完成，再用**同一官方網址**重試並保存前後結果。Agent 不得把尚未進行的手動切換寫成已測試。 |
| 3 | 韓國 IP | 美國、日本均失敗且有可用的韓國出口時再測試。記錄切換者、實際地區及同一網址的結果；沒有可用出口就標記未測，不得推定。 |

## 取得資料與 Demo 的分界

- 官方產品目錄可透過可用出口或唯讀瀏覽器閱讀，逐款保存名稱、ID、類型、數值、來源頁與當次畫面／擷取時間；以完整官方清單核對總數與去重。
- 圖片要核對**確切遊戲映射**、實際 MIME、可讀圖片位元組、視覺標題或官方卡片，以及本地 SHA256。過去 JDB 的官方圖片曾經由 Google Translate 公開圖片代理取得；這是來源存取回退，**不等於已切換桌面 IP**。使用時保留原始官方圖片 URL、代理 URL、同款映射與位元組／視覺證據。若改用第三方同款圖片，必須標示第三方來源。
- 官方目錄卡片、官方新聞、HTTP 200 的遊戲 HTML 殼頁都不能單獨證明 Demo 可用。必須核實**精確單款目的地**、遊戲身份、實際載入結果及登入／地區限制；否則維持 `not-verified` 或實際的 `access-restricted`，不可拿目錄或廠商首頁冒充。
- 單款核心數值若官方頁互相衝突，保存兩份證據並留空有衝突的欄位；切換 IP 不會替衝突做出產品判定。

## 每次 403／限制的接續紀錄

在當批 intake 進度或官方目錄快照中記錄：候選與官方確切 URL、原網路結果（含 HTTP 200 但內容為 403 的情況）、美國／日本／韓國各自的**已測／未測**與證據、成功取得的資料或圖片、仍缺欄位、Demo 的獨立狀態、下一個可執行步驟。若手動日本 IP 尚未切換，下一步明寫等待專案負責人切換；可同時繼續其他可驗證的候選，不得把地區阻擋當成候選耗盡。

## 已知實例

- 2026-10-30 JDB 官方 Slot 目錄在唯讀雲端瀏覽器顯示 46 張卡片，當地直連官方圖片曾回傳 HTTP 200、`text/html` 的「403 Access Denied」頁；部分確切官方圖片透過 Google Translate 公開圖片代理取得，並以官方映射與視覺／雜湊核對。來源與方法見 `data/external-intake/jdb-official-catalog-2026-10-30.partial.json`。
- 2026-10-30 CQ9 官方目錄 `https://site.cq9gaming.com/en/games` 在目前網路回 HTTP 200；唯讀瀏覽器確認共 141 個產品、122 款 Slot。精確的 Treasure Pirate（ID 242）入口 `https://h5c.cqgame.games/h5/242/` 回 HTTP 200，標題與 CQ9 畫面載入；228 個觀察到的資源回應全為 200／304，未見 403 或登入要求。畫面仍停在載入／開場，未證明可完整操作，且瀏覽器沒有顯示公開 IP 或地區；不得聲稱本次已切換美國 IP。CQ9 完整目錄快照見 `data/external-intake/cq9-official-catalog-2026-10-30.json`。
