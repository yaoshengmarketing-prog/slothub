# Game Demo 覆蓋與呈現規則 v1

狀態：APPROVED WORKING RULE

## 目的

Slot Hub 將 Demo 視為遊戲資料的一部分：讓讀者在理解名稱、玩法、版本與來源後，能前往正確的官方測試頁。Demo 不是娛樂城導流，也不使用「立即玩」「試手氣」或獲利暗示。

## 每款遊戲必須保存的狀態

- `available`：已核對可對到該款遊戲的精確官方 Demo 或官方遊戲頁。
- `login-required`：入口存在，但目前需要廠商登入。
- `access-restricted`：核對時受到權限或存取限制。
- `not-verified`：目前未核實精確入口；不等於廠商沒有 Demo。
- `checkedAt` 只在實際核對該款遊戲的 Demo 後更新。目錄仍存在、排程跑過或首頁可開啟都不算重新核對。

## 來源與去重規則

1. 優先使用廠商官方遊戲頁、官方 Demo、官方 Help／Client Hub；其次才是可追溯的官方授權合作方。
2. 連結必須能辨認單款遊戲。廠商 Demo 大廳、通用登入頁或同一網址對應多款遊戲，只能保留為待查線索。
3. 不從搜尋摘要、娛樂城文章或一般資料站直接建立公開 Demo 連結。
4. 中文名、英文名、別名與 Game ID 先對照現有 Game record，避免重複或把 Demo 掛錯遊戲。
5. 找不到、衝突或遭阻擋時記錄狀態並繼續其他遊戲；Demo 缺值不阻擋遊戲發布。

## iframe 與站外連結

- 先區分 `direct-demo` 與 `official-game-page`：前者是可直接啟動的測試內容，後者是含 Demo 入口的官方遊戲資料頁。
- 官方遊戲頁一律以站外連結呈現，不把廠商產品頁誤稱為站內可玩 Demo。
- 只有精確官方遊戲 URL 經真實瀏覽器確認可跨網域載入、無登入阻擋、核心操作可用，才可標記為 `iframe`。
- 只看不到 `X-Frame-Options` 或 CSP，不足以證明可嵌入。
- iframe 日後若啟用，仍須提供同一精確 URL 的站外備援入口；失效時降回站外連結，不更換成猜測網址。

## 前台呈現

- `direct-demo + iframe`：在「快速看懂」後顯示正式的「官方 Demo」資料模組，提供懶載入嵌入畫面、廠商身份、核對日期與站外備援連結。
- `official-game-page + external`：同一位置顯示已核實官方入口與新分頁按鈕，不嵌入整個產品頁。
- 其他狀態：完整資料顯示可理解的狀態文字，不輸出 disabled 按鈕或假連結。
- 不以 Demo 是否存在作推薦、排名或遊戲品質判斷。

## 每日新增與每月回查

每日收集每處理一款遊戲，都要順便核對 Demo 並寫回同一個 Game record；失敗只重試未完成項目。每月回查只在實際開啟並核對精確入口後更新日期。兩者皆沿用既有保存、驗證、Commit、Push 與 Preview 流程，不建立第二套資料 owner。
